  for the quota: three party-line slates — 41 voters score only A1–A4 at 5,

  quota is 66/5 = 13.2, and the A slate holds 41/13.2 = 3.11 quotas, so the
  proportional (Hamilton) answer is 3 A seats + 1 B + 1 C — which is what
  BetterVoting's production tabulator and the published reference
  implementation both elect (A1, A2, B1, A3, C1; confirmed live against
  bettervoting.com on 2026-08-09). This engine instead elects a FOURTH A
  (A1, A2, A3, A4, B1 — D'Hondt's answer) because its allocation round
  measures the quota in ballot COUNTS: every A round retires

  price per seat instead of a full quota. Within each slate the seat order
  is lot-decided (the slate's candidates tie every round), which is why the
  lot order is published in this file; the SEAT SPLIT between slates is
  decided by the ballots alone. Full trace and the upstream reports: this
  folder's README.

=== Three slates, five seats — the count-vs-weight fingerprint ===
  A stress profile built to expose how an Allocated Score tabulator accounts for the quota: three party-line slates — 41 voters score only A1–A4 at 5, 19 score only B1–B3, 6 score only C1–C2 — filling five seats. The Hare quota is 66/5 = 13.2, and the A slate holds 41/13.2 = 3.11 quotas, so the proportional (Hamilton) answer is 3 A seats + 1 B + 1 C — which is what BetterVoting's production tabulator and the published reference implementation both elect (A1, A2, B1, A3, C1; confirmed live against bettervoting.com on 2026-08-09). This engine instead elects a FOURTH A (A1, A2, A3, A4, B1 — D'Hondt's answer) because its allocation round measures the quota in ballot COUNTS: every A round retires 13.2/41 = 32.20% of the A ballots' remaining weight no matter how little weight they still carry, so a big slate pays a geometrically shrinking price per seat instead of a full quota. Within each slate the seat order is lot-decided (the slate's candidates tie every round), which is why the lot order is published in this file; the SEAT SPLIT between slates is decided by the ballots alone. Full trace and the upstream reports: this folder's README.
