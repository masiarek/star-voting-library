# Browse by tag

*The cross-cutting index. The folders answer "which method?" — this page answers "what kind of question?", which is the axis a folder tree cannot show.*

Nine tags, applied to the [cross-method concept pages](07_Concepts/topics/README.md) and to the [approval committee criteria](04_Approval/03_Criteria/README.md) — the two sets of pages that answer a question rather than describe a method. A page carries at most three; a folder's own `README.md` carries none, since it is the folder index rather than a page about anything.

| Tag | What it gathers |
|---|---|
| **foundations** | what are we even optimizing for — before any criterion |
| **reform** | the case for changing the system, and what's wrong with the current one |
| **ballots** | what a ballot lets a voter say, and what the count reads from it |
| **criteria** | properties a method passes or fails |
| **theory** | theorems, impossibility results, the formal machinery |
| **strategy** | manipulation, burial, favorite betrayal, honest-vote incentives |
| **multi-winner** | more than one seat — majoritarian and proportional |
| **simulation** | VSE, spatial models, and where quantitative claims come from |
| **people** | organizations, who's who, and how to learn more |

**Deliberately not tagged by method.** This is a STAR library, so a `STAR` tag would land on two-thirds of these pages and filter nothing — and per-method browsing is already the job of the method folders ([01_STAR](01_STAR/README.md), [02_STAR_Bloc](02_STAR_Bloc/README.md), [03_STAR_PR](03_STAR_PR/README.md), [04_Approval](04_Approval/README.md), [05_Ranked_Robin](05_Ranked_Robin/README.md), [06_Other](06_Other/README.md)). Tags carry the axis those folders can't.
