# The count — how a STAR election is tabulated, step by step

STAR = **S**core **T**hen **A**utomatic **R**unoff. These pages walk the two rounds in order, then answer the questions the second round always raises.

- **[The Scoring Round](STAR_Scoring_Round.md)** — add up the 0–5 scores; the two highest totals become the finalists.
- **[The Automatic Runoff](STAR_Automatic_Runoff.md)** — each ballot counts as one vote for whichever finalist it scored higher; the finalist preferred by more voters wins. ([Slide version](STAR_Automatic_Runoff_slides.md) for presentations.)
- **[STAR's hybrid nature](STAR_hybrid_nature.md)** — why one election uses both a scored round and a majoritarian round, and what each contributes.
- **[Second-round FAQ](STAR_second_round_FAQ.md)** — "doesn't the runoff throw away my scores?" and the other recurring questions.
- **[Runoff percentages](runoff_percentages.md)** — how to read the runoff share honestly (decided voters vs. all voters vs. Equal Support).
