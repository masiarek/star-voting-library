# 05_Ranked_Robin / _main — the worked intro

The single worked introduction to Ranked Robin: the consensus candidate that **plurality** overlooks wins the round-robin outright, because RR compares every pair head-to-head instead of counting only first choices.

| Case (page) | What it shows | src |
|---|---|:--:|
| [the consensus center wins](cases/cases_pages/ranked_robin_consensus_center.md) | RR elects the broadly-preferred center (3–0 head-to-head) over the two poles that hold more first choices | [`.yaml`](cases/ranked_robin_consensus_center.yaml) |

Note: RCV-IRV elects the same winner on these ballots — this case separates Ranked Robin from plurality, not from IRV. For the RR-vs-IRV divergence, see [rr_vs_irv_plurality](../rr_vs_irv_plurality/) (the Tennessee center squeeze).
