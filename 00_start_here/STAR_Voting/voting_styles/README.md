# Voting styles — one page per way to fill out the 5-star ballot

The gallery hub is **[Filling Out the 5-Star Ballot — Voting Styles](../STAR_ballot_voting_styles.md)** (thumbnails, the side-by-side table, and the runnable all-styles election). Each style below has its own page: what the ballot says, when it fits, the honest trade-off, and how that exact ballot fared in a real election.

1. [Traditional](traditional.md) — the choose-one habit, transplanted
2. [Decent Backup](decent_backup.md) — a 5 for your favorite, a 4 for your insurance
3. [Not Much of a Backup](not_much_of_a_backup.md) — a 5, then a grudging 1
4. [Partisan](partisan.md) — the whole slate at 5, nobody else
5. [Ranked](ranked.md) — using each score once, like a ranking
6. [Nuanced](nuanced.md) — the full range, honestly
7. [Anyone But…](anyone_but.md) — every candidate at 5 except the one
8. [Protest Vote](protest_vote.md) — nothing for anyone, except one least-bad 1
